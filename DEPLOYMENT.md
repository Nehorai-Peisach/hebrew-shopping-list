# Deployment Information

## Automatic Deployment Setup ✅

This project is now configured for automatic deployment to Vercel when pushing to GitHub.

### URLs:
- **GitHub Repository**: https://github.com/Nehorai-Peisach/hebrew-shopping-list
- **Production URL**: https://grouped-list.vercel.app
- **Vercel Dashboard**: https://vercel.com/nehoraipeisachs-projects/grouped-list

### How it works:
1. Make changes to your code
2. Commit changes: `git add . && git commit -m "your message"`
3. Push to GitHub: `git push`
4. Vercel automatically deploys the changes

### Features:
- ✅ Complete Hebrew localization
- ✅ RTL (Right-to-Left) support
- ✅ Firebase authentication and database
- ✅ PWA (Progressive Web App) capabilities
- ✅ Responsive design for mobile and desktop
- ✅ Automatic deployment pipeline

### Commands:
- `npm run build` - Build for production
- `vercel --prod` - Manual production deployment
- `vercel` - Preview deployment
