## 🔧 Customization

All design values are CSS custom properties in `src/theme/variables.scss`:

```scss
--ion-color-primary: #6366f1;      // Change brand color
--shadow-lg: 0 10px 15px ...;      // Adjust shadows
--space-lg: 16px;                  // Modify spacing
--transition-base: 200ms ...;      // Change animation speed
```
